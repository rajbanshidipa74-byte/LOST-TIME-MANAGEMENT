# Project Planning and Scheduling
## Lost Time Management System

### 1. Introduction

Project planning and scheduling is the process of identifying project activities, assigning responsibilities, estimating time, and organizing tasks to ensure successful project completion.

The purpose of this document is to establish a development plan and schedule for the Lost Time Management System.

### 2. Project Objectives

The main objectives of project planning are:

- Define the activities required to complete the project.
- Organize development tasks into different phases.
- Assign responsibilities to team members.
- Establish a realistic project schedule.
- Monitor project progress.
- Complete the project within the university submission deadline.

### 3. Project Development Phases

The Lost Time Management System will be developed through the following phases.

#### Phase 1: Project Initiation

Activities:
- Identify the project idea.
- Define project objectives.
- Identify the project scope.
- Identify project stakeholders.
- Prepare the System Request document.

#### Phase 2: Requirements Analysis

Activities:
- Gather functional requirements.
- Identify non-functional requirements.
- Analyze user needs.
- Prepare the SRS document.
- Review and finalize requirements.

#### Phase 3: Planning and Design

Activities:
- Conduct feasibility analysis.
- Perform risk assessment.
- Prepare the project schedule.
- Create the Use Case Diagram.
- Create the Context Diagram and DFD.
- Design the system architecture.
- Design the database.
- Prepare the Activity and Sequence Diagrams.

#### Phase 4: System Development

Activities:
- Develop the Account Management module.
- Develop the Dashboard module.
- Develop the Activity Tracking module.
- Develop the Daily Planner module.
- Develop the Statistics and Lost-Time Analysis module.
- Develop the Profile and Goal Settings module.
- Integrate the system components.

#### Phase 5: Testing

Activities:
- Perform unit testing.
- Perform integration testing.
- Perform system testing.
- Identify and fix bugs.
- Verify system requirements.
- Check overall system functionality.

#### Phase 6: Documentation and Final Submission

Activities:
- Complete project documentation.
- Update diagrams and requirements.
- Prepare the final project report.
- Prepare the presentation.
- Review the GitHub repository.
- Submit the completed project.

The team will monitor project progress using the following methods:

- Conduct regular team meetings.
- Review completed and pending tasks.
- Track changes through GitHub commits.
- Check whether tasks are completed on schedule.
- Identify delays and technical problems.
- Update the project schedule when necessary.
